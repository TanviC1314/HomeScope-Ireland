## Notes and limitations by dataset

- **BHA13** - Regional (not county) grain: planning data are only available by NUTS3 region from the CSO.
- **HOMELESSNESS_MONTHLY** - One CSV per month; column sets changed over time so they are harmonised in data_cleaning.
- **HPM09** - Index (base 2015=100), not euro prices. County detail is not published by the CSO.
- **HSM13** - Source: Dept. of Housing Building Control Management System.
- **NDQ06** - Based on ESB Networks new connections. 'Completions' are new dwellings connected to the grid, a CSO proxy for completions. Latest year is partial.
- **PEA08** - Annual CSO estimates (thousands, rounded); recent years are preliminary and are revised after each Census.
- **RIQ02** - Standardised average rent for new tenancies registered with the RTB. The full table (446 locations) exceeds the API download limit, so only county and city-level locations are requested via a PxStat subset query; values are served unmodified.
- **SCA10** - Covers only households with children, not all households on the list.
- **VAC14** - Vacant = no/low electricity consumption. Does NOT imply the dwelling is habitable or available.
- **counties_osi_2019_gen20m** - Boundaries are for visualisation only (generalised).

Datasets were downloaded through documented open-data APIs only (CSO PxStat REST API, data.gov.ie CKAN API, Tailte Eireann open data download); no web pages were scraped.
